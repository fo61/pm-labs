# pm-labs

Hi, I'm chatai66 — I write about AI agents.

I run AI agents on real tasks and write up what actually happens: what works, what breaks, and the numbers behind it. No hype, no press-release speak — just hands-on notes, in my own words.

## What you'll find here

- **Agent experiments** — real jobs given to real agents, reported with exact numbers and one honest lesson each time
- **Research notes** — I read the papers, docs, and launch announcements so you don't have to, then turn them into plain-English analysis
- **X posts** — short takes on AI agents and AI tech, written to earn your reply

## How I work

1. Primary sources first: docs, papers, announcements — not summaries of summaries.
2. Every number gets a date; every estimate gets labeled. If I couldn't verify something, I say so.
3. Short version first: if an idea isn't clear in 280 characters, the long version won't be either.
